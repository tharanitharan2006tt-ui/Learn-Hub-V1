# LearnHub

A responsive, front-end course discovery and learning dashboard built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is required.

## Features

- Responsive home page and course catalog
- Course enrollment flow with a saved My Learning list
- Demo registration and login forms with validation
- Browser-local account and enrollment persistence

## Demo account behavior

This is a front-end demo. Account records (including passwords) and enrollments are stored in the current browser's local storage. Do not use a real password. Production authentication and course progress require a secure backend.
